# Personal Info Reference Lists

These files are the reference data used by the PII detection logic
(hooks, GitHub Actions, and the org-wide scanner) to match Dutch
first names, surnames, and street names.

| File | Contents | Generated by |
|---|---|---|
| `common-dutch-firstnames.txt` | Dutch first names (10+ occurrences, Meertens voornamenbank) | [`dutch-name-reader`](https://github.com/AmsterdamUMC/dutch-name-reader) |
| `common-dutch-surnames.txt` | Dutch surnames (10+ occurrences, Meertens familienamenbank) | [`dutch-name-reader`](https://github.com/AmsterdamUMC/dutch-name-reader) |
| `common-dutch-streetnames.txt` | Active Dutch street name stems (BAG/PDOK) | [`dutch-streetname-reader`](https://github.com/AmsterdamUMC/dutch-streetname-reader) |

These files are committed directly, not generated at build time. To
regenerate them (e.g. after a new BAG peildatum or an updated Meertens
snapshot), run the relevant generator repo and replace the file here
by hand. See the Technical Maintenance Guide, §[X], for the full
procedure.

Both generator repos are private (internal only).
